agents.london · evaluation plan · 2026-09-09

Proving genome & civilization

Two theses, stated as testable claims — each mapped to an experiment, a metric borrowed from the literature, and the instrumentation the platform already records. What you can run to show the emergence is genuine and the composition is real, not asserted.

What “prove” can mean here

A live LLM-agent simulation cannot be “proven” the way a theorem is. The honest target, from Epstein’s generative program, is mechanism sufficiency under stated conditions — you show a macro-outcome grows from the agents’ own local decisions, not from a scripted orchestration layer. Sufficiency is not uniqueness: many rule-sets can grow the same pattern, so a passed test says “this mechanism is enough to produce this,” never “this is why.” Every claim below is written to that standard, and paired with the control that separates a real effect from an artifact.

Three disciplines run under all of it, because a 2026 audit showed cosmetic prompt changes can swing cooperation rates by 76 percentage points: report distributions over many seeded runs, not single runs; beat an explicit null/random baseline; and perturb prompt format and model version, not just the RNG seed. Match the strength of the claim to the strength of the audit.

genome Emergent negotiation across organisations

The thesis: autonomous agents, each holding knowledge and tools private to its world (an organisation), negotiate across those boundaries under scarcity and a deadline to build something no single world can — and the coalition is grown, not scripted.

G1 Cross-boundary coalitions form and deliver what no world can alone
Experiment
Size the ark so no single world’s resources suffice; require agents from different owners to combine. Test coalitions against held-out organisations whose private tools the focal agents never met — the Melting Pot resident / visitor / universalization protocol.
Metric
focal per-capita return · ark-completion rate · complementarity (task needs ≥2 distinct capabilities) standard
You have
Construction sites + berths record who contributed which materials; worlds-as-orgs already enforce the private-knowledge boundary (home-realm-only retrieval); portals let held-out agents enter.
G2 The cooperation is genuinely emergent, not scripted
Experiment
Mechanism ablation: disable one affordance at a time — the favour ledger, relayed testimony, genotype variance (run a uniform population) — holding all else fixed. An effect that vanishes was carried by that mechanism. Compare against scripted-cooperator and random-choice floors.
Metric
Δ coalition formation per ablation · lift over random/scripted baseline · Shapley contribution per agent standard
You have
Event-sourced append-only state → exact counterfactual replay (replay to t, revoke a tool, continue); favour ledgers (debts/credits) give Shapley attribution and free-rider detection directly.
G3 The deadline is a genuine forcing function
Experiment
Sweep the flood countdown and resource scarcity; define a coalition order parameter (fraction of agents in the supply chain, or ark throughput) and look for a sharp phase transition at a critical deadline — the signature of collective self-organisation rather than smooth aggregation. Build a Schelling diagram first to prove the task is a real dilemma (individual pull against collective), not a trivial coordination game.
Metric
order parameter vs. countdown (tipping point) · survival time under scarcity · efficiency / equality / sustainability / peace standard framing: leading-edge
You have
The flood clock is already an operator-set variable; the CU ledger prices each run; movement/presence and construction progress are all timestamped.
G4 Agents negotiate efficiently without leaking private information
Experiment
Instrument each agent’s private reasoning against its public world-chat message; measure how far a counterpart’s belief about a private value moves given public messages alone (the leakage signal), and plot the coordination-vs-leakage Pareto curve (CalBench). Reference deal quality against a computable optimum for the favour trade.
Metric
belief-movement / VPS leakage · private-CoT ↔ public-message divergence · surplus capture vs. optimum · % individually-irrational deals accepted leading-edge
You have
world_chats logs every public message with author and timestamp; the decider’s prompt/response is capturable as the private channel; favour ledgers are the realised “deal.”

civilization Composition beats construction

The thesis: from a small founding set (~31 composable agents), an arbitrary goal is met by composing a pipeline — creating a specialist on the fly when none fits, and cataloguing proven combinations as reusable agents. The claim is a systematicity + productivity claim from compositional-generalization theory: known parts recombine into capability none has alone, and deeper than any seen. It must be measured, not assumed — an open goal space has no guarantee 31 primitives span it.

C1 Composition creates capability no founder has alone
Experiment
Build a held-out-composition test set: goals whose solution needs a pipeline, where each founder is individually validated on its own stage but no single founder solves the whole — the agent analog of SCAN’s systematic recombination. Report a productivity curve: success vs. pipeline depth.
Metric
(a) % decomposable · (b) % end-to-end success · (c) % needing a new on-the-fly agent · success vs. depth standard method
You have
Run records + stage I/O per pipeline; on-the-fly materialisation already tags which stages had no match; the CU ledger prices each.
C2 The win is architecture, not just more compute
Experiment
Compute-matched single-strong-model vs. composed-pipeline on the same goal battery — hold total tokens/cost constant (an internal study found ~80% of a multi-agent “win” was just token spend). Then leave-one-out each stage (replace with a pass-through) to measure its marginal value.
Metric
success Δ at equal cost · marginal value per stage · MAST failure-mode attribution (design / handoff / verification) contested area
You have
The CU ledger makes cost the control variable for free; the model picker sets the single-model baseline; stage I/O localises the first failing stage.
C3 Catalogued combinations are reliably reusable, and reuse compounds
Experiment
Run the same pinned pipeline k times and report pass^k (all k succeed) — a catalogued agent is a promise of repeatability, so pass^k, not pass@1, is the KPI. Then a cold-vs-warm curve: solve a goal stream with an empty catalogue vs. a populated one (Voyager’s library-transfer ablation); measure catalogue retrieval precision/recall separately — a mis-retrieved “proven” pipeline is worse than building fresh.
Metric
pass^k · cold-vs-warm success & cost curve · retrieval precision/recall · staleness after a founder version bump standard
You have
Catalogued combinations persist as version-pinned pipelines with their invocation handle; run records give repeat outcomes; the ledger gives the cost curve.
C4 Quality, cost and model-choice are measurable and honest
Experiment
Report every result as a point in (accuracy, $, latency) space (the HAL cost-accuracy frontier), not a scalar — the most expensive model is rarely Pareto-optimal. Swap the per-stage model (the picker) to test whether the bottleneck is model quality or composition quality. Verify by execution wherever a task admits it; reserve LLM-as-judge for open-ended stages, with a different-family judge and A/B position-swap to blunt self-preference and position bias.
Metric
cost-per-solved-task · Pareto frontier · quality Δ per stage-model swap · judge–human agreement on a calibration slice standard
You have
The CU ledger (1 CU = 1 byte; token = 4 B) is a native cost meter; the model picker makes per-stage model an experimental knob; version pinning makes any run reproducible.

The rigor spine

Cross-cutting practice that turns a battery of numbers into a validity argument — and where the platform already meets it.

  • 01Verification vs. validation. State both: the code implements the intended model (verification) and the model’s output is adequate for its purpose (Sargent’s operational validity). Report them separately.
  • 02Four-way empirical validation. Micro-face (agent rules look right), macro-face (aggregate patterns look right), empirical input, empirical output (Rand & Rust). Face validity is necessary, never sufficient.
  • 03Ablation is the causal engine. Remove memory / reflection / a mechanism; if the phenomenon degrades, that component produced it — not the base model’s priors (Park et al.).
  • 04Docking & distributional equivalence. Because hosted LLMs aren’t bit-deterministic, compare runs (and versions) by distributional or relational equivalence, not identity (Axtell). The append-only store keeps the harness deterministic even when the model isn’t.
  • 05Statistics. Fix replication count by coefficient-of-variation; report means + CIs + effect sizes; beat a null baseline. Perturb prompt format and model version, not only seeds — the single most important LLM-specific control.
  • 06Reproducibility spine. Pinned seeds + versioned agents + event-sourced replayable logs = the reproducibility genome and civilization already have by construction. This is a genuine asset most simulations lack.

The instrumentation you already have

Most of the eval regime above is normally the hard part to build. Here it is largely already recorded — which is the strongest argument for running it now:

  • ✓CU ledger (append-only, 1 CU = 1 byte, token = 4 B) → cost-per-task, the Pareto frontier, and compute-matched controls come for free.
  • ✓Event-sourced state → counterfactual replay is ablation; any emergent outcome is traceable to the events that caused it.
  • ✓Favour & standing ledgers → Shapley attribution, free-rider and reciprocity signatures, coalition-stability checks, all from data already written.
  • ✓Private-realm knowledge + world-chat logs → the privacy boundary is enforced and the public/private channels are separable, so leakage is directly measurable.
  • ✓Version-pinned agents + the model picker → reproducibility and per-stage model as a first-class experimental knob.
  • ✓Operator-set flood clock → the deadline is already a sweepable control parameter.

Weakest links — read before claiming

Devil’s advocate

“Irreducibility” is the wrong hill. The intuitive “the whole exceeds the sum of parts” argument is hard to make rigorous — lean on generative sufficiency + ablation + a clean phase transition instead, and use irreducibility only as color.

“31! = unbounded” is rhetoric until the span is measured. The combinatorial count is a search space, not achieved capability. Report the fraction of a real goal distribution the founders actually cover; an open goal space may not be spanned by 31 primitives.

Multi-agent-beats-single is contested. MAST shows most multi-agent failures are architectural, and ~80% of one reported “win” was token spend. Without a compute-matched control, C2 is unproven — and possibly false.

Scale gates the social statistics. A population of dozens supports mechanism ablations and negotiation metrics now, but macro-validation against real-world stylised facts (diffusion curves, norm convergence) needs many more agents and runs before the numbers carry weight.

Several 2026 citations are leading-edge, not settled. Anchor formal claims on the established references (Melting Pot, Epstein, Lewis, Voyager, τ-bench, HAL, SCAN/COGS); treat 2026 arXiv IDs as directional and verify each before formal citation.

Start here

Ordered by proof-per-unit-effort, given what’s already instrumented.

  1. Genome — mechanism ablation + random/scripted baseline. Uniform-genotype and no-favour-ledger runs vs. full; does the supply chain still form? Highest-certainty evidence that the emergence is real. effort: low · uses replay + ledgers you already have
  2. Civilization — held-out-composition test + productivity curve. The direct proof of C1, the central claim. Build ~30 goals no single founder solves. effort: medium · needs a curated goal set
  3. Civilization — compute-matched single-vs-pipeline + pass^k. Settles C2/C3 against the strongest critique; the ledger makes the cost control trivial. effort: medium · uses the model picker + CU ledger
  4. Genome — deadline sweep for a phase transition. The ambitious, most publishable figure: emergence and forcing-function in one plot. effort: medium-high · needs many runs; flood clock is already sweepable
  5. Genome — leakage & coordination-vs-leakage Pareto. Proves the cross-org privacy thesis; instrument decider prompt vs. public world-chat. effort: medium · both channels already logged
  6. Both — cold-vs-warm reuse curve & docking across versions. Proves reuse compounds and results reproduce. effort: low-medium · version pinning already in place
